# Friction Log

Recurring pain points encountered by agents. Sorted by hit count so the worst offenders float to the top.

**For agents:** Don't read this proactively. If you hit friction during your work, open this file and either increment an existing entry's hit count or add a new one at the bottom. Then get back to your actual task.

**For Jason:** Review periodically. High hit counts = high-value fixes.

---

## Format

```
### Short description
**Hits:** N
**Area:** file, tool, or system involved
**What happens:** what goes wrong or is confusing
**Workaround:** how agents have gotten past it (if known)
**Last hit:** YYYY-MM-DD
```

When incrementing: bump the Hits count and update Last hit. Add to the Workaround if you found a better one.
